# Convenience columns copy one Primary Detector

Seurat, SingleCellExperiment, and AnnData users expect convenience fields `doublet_score` and `predicted_doublet`. This context reports every Detector side by side and does not fuse Calls (ADR 0004). Copying one **Primary Detector** (default scDblFinder) into those columns, plus `is_doublet` as the same boolean as `predicted_doublet`, satisfies both ecosystems without inventing a consensus. Per-Detector `{name}_score` and `{name}_call` remain on the object. Changing the meaning of `predicted_doublet` later would silently retarget every workflow that subsets on it.
